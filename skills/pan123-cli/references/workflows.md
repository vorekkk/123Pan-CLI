# 任务流程

完整行为说明和所有例子在 [完整命令](commands.md)，准确 parser 参数在 [帮助全集](parser-help.md)，字段及限制在 [API 映射](api-mapping.md)。以下命令中的 ID、路径必须替换成用户真实目标，不直接照抄示例数字。

## 浏览与定位

先 `pan123 file list --help`，按目录 ID 列出；需要完整范围时加 `--all`。列表默认推荐 V2，`--api-version v1`仅兼容旧版需求。按返回 ID 查详情，核对名称、类型、父目录和大小。不要跨页遗漏或把重复名称当唯一标识。批量详情与分页使用命令参考中的对应命令。

## 上传

优先 `pan123 file upload --help` 所提供的高层本地上传流程；确认本地文件及父目录 ID，再运行。高层流程负责哈希、创建会话、分片、完成和校验。重名策略必须来自用户意图。目录上传及递归等能力以实际帮助为准，不猜参数。

需要精细控制时使用 `file upload-api` 的 V2 推荐流程。先创建文件；秒传返回成功时无需上传分片。否则用会话指定的上传域名/URL 上传，再完成，并按官方说明轮询确认。旧 V1 流程只在明确需求时使用。不要混用 V1/V2 的 session、上传域名及分片协议。文件内容改变时停止并重新创建会话；无法确认写请求结果时先查状态，不直接重试创建。

上传结果要读取文件详情核对大小和哈希（若接口提供），将返回 file ID交给后续任务。只有 token 获取、上传地址获取成功不能报告上传成功。

## 下载

`pan123 file download --help`了解本地路径、覆盖及校验参数。先取详情，确认目标文件；高层下载获取受校验的官方地址并落盘。失败留下的 part 文件不能当成功结果。下载 URL带查询 token 时不要记录到公共日志。下载后核对本地文件大小及 CLI 提供的完整性结果。

## 文件写操作

创建目录、重命名、移动、复制前读取目标目录和对象详情。批量 ID 字段用实际帮助提供的重复参数或 JSON 请求文件；保持顺序/数量限制，不能直接拼接未经验证的任意 JSON。复制操作可能异步，使用进度查询或 `--wait`（若支持），确认终态再报告结果。

删除至回收站可恢复，永久删除与清空回收站另有命令；按用户授权选择。不能为了测试工具而对真实云盘执行删除。回收站恢复必须核对恢复目标目录。

## 分享

普通分享与付费分享分别使用相应命令，核对期限、密码、文件集和计费设置。密码通过对应 stdin 标志传入，不出现在 argv。创建分享后读取分享详情确认；修改后读回生效值。公开分享链接可能授予访问权限，仅交付给用户请求的范围。

## 离线任务与转码

创建任务返回 ID只是已提交。查询任务/进度，支持的命令使用 `--wait --wait-timeout`。超时后保留任务 ID，继续查询，不重复创建。业务失败或不支持的格式应报告脱敏业务错误。离线删除/清理与创建下载是不同授权。

## 直链和图片

先核对账号权益、空间状态。启用/禁用空间、黑名单配置、刷新缓存都具有实际副作用。流量日志和离线日志有分页及日期要求，按映射核对字段，不假设免费。图片上传和文件上传接口独立；转码、图片任务只使用其返回 ID。

## 故障排查

- 配置缺失：本地 `pan123 setup`；自动化用环境变量；不要向 AI 提交 secret。
- 鉴权失败：确认 developer/OAuth 模式与凭据来源，必要时清 token 缓存后重试读操作；清缓存不是删除账号。
- 限流/网络：读取错误 retryable 和重试限制。写请求不盲重试；先查询是否已完成。
- 权益不足：报告功能对应权限/权益，不假造 IP 或绕过服务限制。
- 本地冲突：核对路径和覆盖意图，避免自动覆写用户文件。
- 协议/完整性：保留脱敏 trace_id，检查官方当前资料；不要将 not_verified 能力标为已真实验证。
