# 接入流程

> 此接入流程仅适用于API接口的调用链接

# 1\. 购买开发者权益包

请您阅读[开发者服务协议](https://www.123pan.com/DeveloperAgreement)，并[开通开发者权益包](https://www.123pan.com/member?productKey=vip&source_page=vip_button&tabKey=1)，开通后会将`client_id`和`client_secret`以“站内信-消息”形式发送给您，请您妥善保存！

# 2\. 获取访问凭证

访问凭证（也称为 `**access_token**`）。调用 API 时，需要在 HTTP Header 中携带访问凭证。有关访问凭证的介绍详见 [获取access\_token](https://123yunpan.yuque.com/org-wiki-123yunpan-muaork/cr6ced/gn1nai4x0v0ry9ki)

# 3\. 调用 API

完成上述步骤后，就可以调用 API 了
