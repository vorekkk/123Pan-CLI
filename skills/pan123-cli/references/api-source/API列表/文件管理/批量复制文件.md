# 批量复制文件

API： POST 域名 + /api/v1/file/async/copy

说明：批量复制文件，单级最多支持3000个

## Header 参数

| 名称 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| Authorization | string | 必填 | 鉴权access_token |
| Platform | string | 必填 | 固定为:open_platform |

## Body 参数

| 名称 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| fileIds | array | 必填 | 文件id数组 |
| targetDirId | number | 必填 | 要复制到的目标文件夹id |

## 响应参数

| 名称 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| taskId | number | 必填 | 任务id，后续用来查询任务进度 |

## 示例

**请求示例**

```shell
curl --location 'https://open-api.123pan.com/api/v1/file/async/copy' \
--header 'platform: open_platform' \
--header 'Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI...(过长省略)' \
--header 'Content-Type: application/json' \
--data '{
    "fileIds": [1758176091067],
    "targetDirID": 0
}'
```

```java
OkHttpClient client = new OkHttpClient().newBuilder()
  .build();
MediaType mediaType = MediaType.parse("application/json");
RequestBody body = RequestBody.create(mediaType, "{\r\n    \"fileIds\": [1758176091067],\r\n    \"targetDirID\": 0\r\n}");
Request request = new Request.Builder()
  .url("https://open-api.123pan.com/api/v1/file/async/copy")
  .method("POST", body)
  .addHeader("platform", "open_platform")
  .addHeader("Authorization", "Bearer eyJhbGciOiJIUzI1NiIsInR5cCI...(过长省略)")
  .addHeader("Content-Type", "application/json")
  .build();
Response response = client.newCall(request).execute();
```

```python
import http.client
import json

conn = http.client.HTTPSConnection("open-api.123pan.com")
payload = json.dumps({
  "fileIds": [
    1758176091067
  ],
  "targetDirID": 0
})
headers = {
  'platform': 'open_platform',
  'Authorization': 'Bearer eyJhbGciOiJIUzI1NiIsInR5cCI...(过长省略)',
  'Content-Type': 'application/json'
}
conn.request("POST", "/api/v1/file/async/copy", payload, headers)
res = conn.getresponse()
data = res.read()
print(data.decode("utf-8"))
```
