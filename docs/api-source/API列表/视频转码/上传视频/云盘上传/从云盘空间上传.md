# 从云盘空间上传

API： POST 域名 + /api/v1/transcode/upload/from\_cloud\_disk

## Header 参数

| 名称 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| Authorization | string | 必填 | 鉴权access_token |
| Platform | string | 必填 | 固定为:open_platform |

## **Body 参数**

| 名称 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| fileId | []objet | 必填 | 云盘空间文件ID注意：一次性最多支持100个文件上传 |

### body参数示例

```json
[
    {
        "fileId": 2875051
    },
    {
        "fileId": 2875052
    }
]
```

## **返回数据**

文字提示：上传成功
