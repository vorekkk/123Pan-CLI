# 批量复制文件进度

API： GET 域名 + /api/v1/file/async/copy/process

## Header 参数

| 名称 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| Authorization | string | 必填 | 鉴权access_token |
| Platform | string | 必填 | 固定为:open_platform |

## Body 参数

| 名称 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| taskId | number | 必填 | 任务id |

## 响应参数

| 名称 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| taskId | number | 必填 | 任务id |
| status | number | 必填 | 任务状态：0-待处理 1-进行中 2-已完成 3-失败 |

## 示例

**请求示例**

```shell
curl --location --request GET 'https://open-api.123pan.com/api/v1/file/async/copy/process' \
--header 'Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXV...(过长省略)' \
--header 'platform: open_platform' \
--header 'Content-Type: application/json' \
--data '{
    "taskId":2016
}'
```

```python
import http.client
import json

conn = http.client.HTTPSConnection("open-api.123pan.com")
payload = json.dumps({
  "taskId": 2016
})
headers = {
  'Authorization': 'Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ...(过长省略)',
  'platform': 'open_platform',
  'Content-Type': 'application/json'
}
conn.request("GET", "/api/v1/file/async/copy/process", payload, headers)
res = conn.getresponse()
data = res.read()
print(data.decode("utf-8"))
```
