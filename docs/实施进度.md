本机环境：macOS 27.2 `arm64`、CPython 3.14.7（真实验证只在 macOS ARM64 上执行）。本机代理使用 Fake-IP DNS，真实上传需显式 `--allow-fake-ip`。

CI 首轮暴露并已修复两个只在 Windows 出现的问题，两者都有回归覆盖：

- `mypy` 在 Windows 类型存根下拒绝 `os.getuid` / `os.fchmod`（即使位于 `os.name == "posix"` 分支内）；现统一经 `cache.owner_uid()` / `cache.set_private_file_mode()` 调用，平台缺少这些函数时安全跳过。
- `python -m pan123_cli --help` 在 ANSI 代码页管线下抛 `UnicodeEncodeError`（属于 `ValueError`）并以退出码 2 失败；现于启动时把 stdout / stderr 重配置为 UTF-8，并有 `PYTHONIOENCODING=cp1252` 子进程用例。
